## 撤回的旧结论

旧稿曾断言“原版倍率上限5×”“常驻翼必然是mod”，并据此把该视频认定为修改版。现撤回这些判据：

- 当前计分将本局ScoreMultiplier与金币充能等级区分；objectives.ts通过原完成目标计数规则计算下一局倍率。没有本次代码证据支持把所有倍率统一限制为5。
- 原StartAngelWings/Controller代码存在本局永久翼状态：激活后不按普通30秒倒计时，触发死亡时消费并单独冷却。看到长时间翅膀不能单独证明修改版，也不能推导出永久无敌。
- 用户指定长视频的连续结尾画面可见52×。这只是该录像的显示值，既不证明所有版本上限，也不构成修改版身份的充分证据。
- 早期笔记所称后段“冻结/重复”，没有在本轮重新核验。应与播放器缓冲、未解码旧帧和源录像重复分开，不直接当作游戏流程规则或版本鉴定。

因此本页不再给出“视频必为mod”的确定结论；也不反向证明它一定未经修改。

## 旧实现描述不再适用

旧稿对“当前网页”的两条安全道、5×上限、没有翅膀、亮蓝环境、缺T口等描述来自早期实现，不能指导当前版本改动。当前beats-v7已采用原支撑多边形、窄路安全侧、三主题、翅膀/起跑、原目标计数适配、T口和分路；实现与范围见验收表，不在历史页面复制一份容易过期的状态表。
