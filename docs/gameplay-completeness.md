# 当前目标：玩法完备 + 完整可玩

2026-10-31，Minghao 最新指令取代原来的 1:1 复刻目标。对齐玩法、机制、手感；不以逐帧、分数时序、投影或像素一致验收。保留参考录像与原版静态分析作为证据，不能把录像脚本当随机生成规则。

“有”仅表示实现存在；必须另记可达性和实玩验证。“不准”包括已知假设、机制不完整、与当前目标不符。视频未展示或无法确认的项目如实注明，不能把用户要求等同视频证据。

## 推进顺序

1. 保留并扩展左右输入回归；修复升级购买后不生效、道具交互等直接功能问题。
2. 逐型可玩验收：每类障碍成功与失败、道具拾取/生效/结束、金币宝石、死亡复活及结算防重。
3. 静态恢复原版路径/配置逻辑，建立内容可达、留足反应距离且可重现的生成器；将录像脚本保留为回归夹具，逐步脱离普通流程。
4. 商店、升级、存档完整闭环；手机实机手感与后期随机种子覆盖。
5. 必要视觉精修，不恢复像素级验收。

## 第1轮结果：升级生效与道具/结算闭环

### 补齐和修复

- 新增“护盾时长”“金币奖励”升级；磁铁购买后在默认模式实际生效。
- 默认护盾从录像高等级固定25秒改为玩家等级决定：基础15秒，升级17.5/20/22.5/25秒；磁铁15→20→25秒；奖励金币50→75→100→125→150。
- 已恢复的原版等级存在重复效果，本项目用精简等级跳过无增益档，避免花钱后效果不变。等级映射与价格是本项目假设，效果数值来自原版表。
- 原有web金币价值升级现也作用于默认模式；每级+25%收益仍是保留的web经济假设，不是原版高值币阈值机制。小数累计，4枚普通币在一级时给5金币。
- 磁铁原来会对所有拾取物使用9m范围，远处护盾/宝石会被直接拾取。已复现并改为只吸金币；远处护盾不再覆盖当前磁铁。原版 IsACoin 只允许枚举1/2/3。
- 默认HUD显示当前道具与剩余秒数，玩家不必打开辅助模式才能知道道具正在生效。

### 原版证据

重新运行 `tools/inspect-native-coin-bonus.py`，静态核验 `GameController.LoadLevelInformation` 的时长/奖励表；新增核验 `HandleBonusItemPickup 0x1270ed0 → BonusItem.IsACoin 0x1296070`，非金币分支跳过吸附。完整记录：`target/temple-run/analysis/native-coin-bonus-source.json`。

新增 `tools/inspect-native-gameplay-generation.py`：通过IL2CPP方法token定位并导出 `GetRandomPathElementForSide`、`AddRandomPath`、`AddCoins`、`AddBonusItems`、静态构造器，保存RVA/哈希/静态字段偏移。重新核验6格间距、50格道具、串数5、连续障碍2等静态默认值。证据：`target/temple-run/analysis/native-generation/source.json`。静态默认值可能被配置覆盖；方法导出不等于权重和生成分布已解码。

## 第2轮结果：磁铁与护盾共存，独立计时

- 复现：先拾磁铁、再拾护盾后，隔道金币不再被吸取。根因是所有限时道具共用 `kind/until` 单槽。
- 修复：每类道具保存独立截止时间；全部真实碰撞、吸币、速度、缺口支撑、角色材质和HUD判断使用各自的有效状态。拾取一种道具不再清除另一种；重复拾取只刷新自身。HUD同时显示各项剩余时间，单项到期后其他效果继续显示。重开清空所有道具。
- 原版来源：`tools/inspect-native-power-stacking.py` 静态核验并保存 `StartInvcibility`（原版方法拼写）、`StartVacuum`、`StartBoost` 方法名、RVA、哈希和指令。磁铁使用16c/170，护盾使用154/158；开始方法分别赋值自己的剩余时间。材料设置辅助方法也已检查。证据在 `target/temple-run/analysis/native-power-stacking/source.json`。
- 加速限制：本轮仍保留web的5秒计时加速。原版 `StartBoost` 实际管理距离，并在首次开始调用4秒无敌；网页目前不替换已有护盾计时。这部分仍不准，下一轮应整体迁移距离、速度/减速、过弯与附带无敌规则，不能把当前三项计时槽声称为完整原版加速机制。
- 实玩：通过真实拾取物+update/collision完成10项浏览器断言，验证双道具吸币/撞障保护、三项同时存在、加速单独到期、重复磁铁刷新、护盾到期后磁铁仍吸币、重开清理以及失败→结算→重开。测试中正常发送路口转弯指令；没有关闭真实碰撞。开始验证时发现当前加速不会自动转弯，此行为另列入加速规则待审，未用无敌掩盖。
- 回归脚本：`tools/test-temple-stacking.browser.js`；结果：`target/temple-run/analysis/gameplay-stacking-regression.json`；截图：`gameplay-stacked-hud.png`。这是注入拾取物位置的QA夹具，不代表生成频率已完成。
- 模块测试 `temple:test:power-effects` 验证独立到期、刷新和新局清理；升级、steering、turn、类型检查和构建通过。最终10项叠加与15项左右输入/5500m回归全部通过，结果已保存。

上一轮的“多道具共用槽”缺口已解决。下一步优先原版加速机制与原版随机生成；长坑/窄路/分支合流的正常覆盖与手机真机手感仍未完成。
