# 玩法架构证据图

发布地址：https://malcolmyu.github.io/temple-run/design-evidence/

这是按八个维度整理的28项设计审计，不是逐秒帧墙。首页先给一局状态流程，再给结论、关键帧、来源类别、规则、实现状态和固定版本代码链接。状态表示实现覆盖，不表示本轮逐项进行了玩法验收。

## 来源与边界

- 原版 il2cpp：已有逆向成果中提取的规则；链接到注释含地址/函数的规则模块。完整拓扑原始证据入口是 `docs/original-topology-evidence.md`。
- 原版资源：提取的几何、支撑多边形、图集或资源目录；网页缩放/组合不自动成为原版规则。
- 视频观察：只证明对应帧可见的形态或行为。索引为视频秒位，不是画面中的局内计时器；00:00是悬崖插入片段。
- 网页假设：本项目状态机、生成调度、安全预算、固定分支合流、宝石经济等适配。

本片未直接证实磁铁、加速、天使翼、起跑道具、宝石用途与商店交互；页面明确保留这个缺口。原版图集裁片另标“原版资源”，不充当视频帧。

T口有真实几何与四向连接。固定双臂分支再合流没有足够原版依据，列为网页设计。高位火塔与网页低火墙分开；蓝色坑面不作为悬崖主题证据。

## 维护与构建

内容源：`content.json`。页面样式/交互：`tools/design-evidence.css`、`tools/design-evidence-client.ts`。

运行 `npm run temple:evidence:build` 重建发布页，再运行 `npm run temple:evidence:verify`。生产构建验证8维度、28项、固定审计提交中的源文件SHA-256、关键帧源哈希与附录链接；规则变化后须重新审阅内容并更新审计快照，不能只刷新哈希。

发布清单 `evidence.json` 包含逐条来源路径与哈希；`timestamps.json` 和本目录 `timestamps.md` 给出各维度时间戳。

原271帧保留在 `/screenshots/BV1ypuKzPErT/frames.html` 起的16页附录；旧 `/screenshots/BV1ypuKzPErT/` 首页跳转证据图。附录旧注释是检索提示，设计结论以本页复核为准。

## 本轮验证

- 类型检查、资源校验、证据源/帧哈希校验、生产构建。
- Chrome实际检查桌面与375像素窄屏：八维目录、状态筛选、关键帧大图与关闭、原视频秒位链接、原版图集裁片、无横向页面溢出。
- 本轮没有修改游戏运行逻辑；没有把文档页面检查当成新一轮玩法回归。
