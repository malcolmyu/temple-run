# 可玩性优先验收（2026-10-31）

当前主清单与后续验证更新见 [gameplay-completeness.md](gameplay-completeness.md)，下文保留换道修复首轮记录。

暂停逐帧、时间、分数、投影的严格对齐。

## 本轮修复

- 普通道路的左/右指令原来进入经典模式“转弯被拒绝”分支，0.25 秒后主动绊倒；开局追逐计时使其直接死亡。现在先尝试路口转弯，未接受则换道，并在最外车道限幅。
- 无倾斜传感器或 A/D 持续输入时，原来仍返回 0 轴值，每帧覆盖换道目标。现在返回 null，保留所选车道。
- 跳跃、滑铲中允许换道；坠落后不再接受换道。真实障碍和漏转失败逻辑保留。
- 菜单说明更新为“← → 换道 / 路口转弯”；A/D 保留连续横移，倾斜操作仍需主动开启。

## 已实际验证

可重复浏览器回归：`tools/test-temple-playability.browser.js`。通过真实 Input 监听器和游戏 update 推进，不使用跳点、无敌、改障碍或关闭碰撞。时间由调试 advance 加速，不能代替真人实时手感测试。报告：`target/temple-run/analysis/playability-regression.json`。

15 项断言通过：左右换道、两侧连续按键限幅、两侧空中换道、滑铲换道、左右指针滑动、前两个右转及第三个 T 字路口两侧、5500 米路线、真实树根碰撞、漏转失败、失败进入结算。

长程经过 42 个路口、石路→木桥→石路→木桥→石路四次切换。两段木桥当前边界为 1320–2244 米、4308–4908 米；这些是已有估算路段，本轮未为视频对齐改长度。桥面接缝/高差按现有设计用跳跃通过。

另外通过浏览器可见按钮实际点击“再跑一次→暂停→继续奔跑”，分数、路程、车道重置正确；继续后真实键盘 ArrowLeft 正常换道。截图在 `target/temple-run/analysis/playability-results.png` 和 `playability-left-lane.png`。

类型检查与构建通过；steering、turn、route、t-junction、terrain 测试通过。构建仍有既存 legacy 图片路径、音频包体积提示。

## 尚需补齐或进一步验收

- 5500 米以后的程序生成路段尚未做持续长跑与多随机种子覆盖；最后一段主题目前持续使用石路。
- 手机真机的连续手势、倾斜权限与响应，以及窄屏结算布局还未实测；本轮指针滑动为浏览器合成事件。
- 商店、宝石复活、跨刷新存档与重复结算防重入未纳入本轮专项验收。
- 主题变化提示、难度与障碍组合的真人可读性需要实际游玩评估；自动控制能通过不能替代手感验收。
- 必要视觉贴近排在功能稳定之后；不恢复逐帧一致门槛。
