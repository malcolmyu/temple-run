# 神庙逃亡 · Web Runner

基于用户提供的 `temple-run.xapk` 制作的可玩 3D 网页版。使用从 APK 中导出的默认探险者和追逐者网格、皮肤，以及石墙和树木图集。跑道会弯曲，路口有实际的 90° 转角；绊倒后追逐者靠近，再次绊倒会被抓住。跑道生成、障碍、物理、人物动作和追逐机制由 Web 实现；它不是原版 Unity 游戏的完整移植。

## 运行

在仓库根目录执行：

```bash
npm install
npm run temple:dev
```

打开 Vite 输出的本地地址。构建发布版：`npm run temple:build`，产物在 `target/temple-run/dist/`。

## 玩法

转弯操作：路口前约 40 个单位会出现箭头与倒计时提示，在提示期间按对应方向（或滑动）即可转向；错过会撞上断头墙。

- `←`、`→` 或 `A`、`D`：换道；靠近路口时按提示方向转弯
- `↑`、`W`、空格：跳跃，越过矮栏或断桥
- `↓`、`S`：滑铲，穿过石门
- `P` 或 `Esc`：暂停
- 手机可用滑动手势或屏幕按钮操作

收集金币，躲避障碍，尽量跑得更远。奔跑速度固定，不会随距离加快。撞击、被抓或坠落时会先播放短暂的场景动画，再显示结算。历史最远距离保存在浏览器本地。右上角可静音与暂停。

## 调试与素材工具

- `rig-preview.html`：查看 APK 原始蒙皮角色与 run/jump/slide 动画
- `track-preview.html`：查看导出的原版路面/护墙/树木素材
- 游戏内 `window.__templeDebug` 提供 `restart` / `freeze` / `thaw` / `jumpTo(d)` / `attemptTurn(dir)` / `setNextTurn(d)` / `end(reason, kind)` 等回归测试接口，`window.render_game_to_text()` 输出当前状态。

## 素材与实现

APK 内的角色、敌人和贴图由 UnityPy 导出，分析记录见 [`analysis/source-notes.md`](analysis/source-notes.md)。Web 端使用 Three.js、Vite、Web Audio API。结束动画由 Web 端制作；Unity 的原始动画、关卡数据及运行逻辑没有移植。这些导出的素材属于原游戏；公开发布或分发前需确认相应使用权。

- 2026-10-23 补充：障碍预制体目录 `web/public/assets/obstacles/`（23 个原版网格，来自 APK 静态布景；树干类用 treeTexture，石材类用 wallTexture，全部 DoubleSide/alphaTest 0.4）；调试页 `obstacle-preview.html` 可逐件查看；自动回归脚本模式：`window.__templeDebug` + `advanceTime` 按 cue 转弯/跳跃/下滑。浏览器控制台可用 `__templeDebug.jumpTo(n)`、`spawnObstacle(kind,ahead)` 快速复现。

## 性能与资源（第 182 轮实测）

- 帧率：桌面 1280×720 与移动端 390×844 均为 **60fps**（median 16.7ms / p95 16.8ms，无掉帧）
- 渲染：中段 avg draw calls ≈ 400–800，三角形 ≈ 2–11 万（随地貌/视野变化）
- GPU 资源：一次完整跑（1656m/18 弯）geometries 189 → 281、textures 29 → 40，之后**饱和不再增长**（2.8km 长跑复核零增长）
- 对象池：flames/sparks/coins/obstacles 等在跑完后与途中一致，无泄漏
- WebAudio：真实时间测试 created == ended、active 0；模拟快进时节点数会累积（WebAudio 时钟不随 advanceTime 推进，属测试假象）

## 验收记录（第 193 轮）

- 启动/菜单：`state=menu`，样式表 1 张，`__templeDebug` 就绪
- 交互：`ArrowUp` → jumpY 0.86；`ArrowDown` → sliding 0.90；`ArrowRight` → lane 1→2；`Escape` → paused；暂停面板「继续奔跑」恢复 playing
- 转弯：cue 剩余 39m 时按键 → `turnQueued`，穿越后 `turnCount=1`；漏按则 57+2m 处 `错过路口` 死亡
- 面板：商店 / 目标 / 统计 / 设置 均可打开并返回
- 结算：`ended` 状态显示 4 项统计 + 累计金币；宝石复活 → 回到 playing
- 移动端 390×844：竖屏布局、HUD、触控、结算面板正常；渲染 60fps（1.5s 采样 worst 23.5ms）
